How this works

Ten simulated devices each stream four features every tick — request rate, round-trip latency, authentication-failure rate, and packet-size jitter — against a baseline drawn per device at load. Roughly one tick in twelve (configurable above), a random device is pushed into an "attack" state for a few ticks, shifting those features well outside its baseline — or trigger one yourself from the controls panel.

Before training, scoring falls back to a simple per-device z-score heuristic. Pressing train generates 500 labelled synthetic samples from the same feature distributions, standardises them, and runs full-batch gradient descent by hand — forward pass, MSE loss, backpropagation, weight update — for 220 epochs, plotting the loss live. Once trained, the network takes over live scoring of every device on every tick. Trained weights can be saved to this browser's local storage and reloaded automatically next visit.

Nothing here calls an API or a server: the mesh, the training data, the network, and the visualization all live in this one HTML file, which is what makes it deployable as a static GitHub Pages site.
